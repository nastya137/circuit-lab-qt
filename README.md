# Виртуальная лаборатория по электрическим цепям

Учебное настольное приложение на C++ и Qt для выполнения двух лабораторных работ: с мостом Уитстона и схемой измерения ёмкости. Разработано как курсовой проект в 2024 году.

## Возможности

- Выбор лабораторной работы в стартовом меню.
- Сборка цепи: соединение узлов проводами щелчками мыши.
- Включение установки и изменение положения реостата колесом мыши.
- Отображение показаний стрелочного индикатора при изменении схемы.
- Просмотр теории и проверка ответов на вопросы лабораторной работы.

Для расчётов соединения элементов представлены графом. Приложение обходит соединения и определяет замкнутые контуры для заданных мостовых схем. Расчётная часть ориентирована на эти две работы, а не на произвольные электрические цепи.

## Технологии

C++ · Qt Widgets · qmake · алгоритмы обхода графа

## Сборка и запуск

1. Откройте `kproj.pro` в Qt Creator.
2. Выберите установленный комплект Qt, совместимый с исходным кодом проекта.
3. Соберите и запустите приложение. Стартовое меню позволит выбрать одну из двух работ.

Проект опубликован как учебная работа. Сборка на последних версиях Qt пока не проверена; исходный файл `kproj.pro` содержит зависимость от Qt WebKit. Если в вашей установке Qt этого модуля нет, удалите `webkit` из строки `QT += ...` перед сборкой: в исходниках приложения API WebKit не используется.

## Структура проекта

- `startmenu.h` — меню выбора работы и теоретические материалы.
- `schemewindow.h` — работа с мостом Уитстона.
- `capacitorsmeasure.h` — работа по измерению ёмкости.
- `kirhgofcount.h` — представление соединений и расчётная логика.
- `meterciferblat.h`, `reostat.h` — отрисовка индикатора и реостата.
- `res.qrc` — изображения и исходные данные схем.
